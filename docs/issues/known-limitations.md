# 已知限制

本文件保留公开快照中的功能边界，不包含原环境的运行记录。

- 密钥与个人信息扫描使用启发式规则，不能覆盖全部敏感内容形态。
- 备份包含 Artifact 索引，内容文件需要另外备份；磁盘配额需要显式配置。
- Windows 安装、升级和卸载目前使用脚本，没有独立安装程序。
- OpenViking 的候选创建、生效、取代、撤销和导出写路径未全部接入；在线服务可能返回 503。
- Skills 自动生成机制尚未实现；concurrent 编排和无进展自动终止仍有缺口。
- 部分 RoomRun 取消流程可能停留在 CANCELLING，缺少最终状态驱动。
- job 命令应显式声明 `arguments: []`，省略参数数组可能导致校验失败。
- 项目登记通过 API 内联 JSON，不自动扫描目录，也不自动读取项目内 YAML 文件。
- `WB_PROJECTS_ROOT` 未设置时没有全局登记根限制；按使用环境明确设置。
- 根 `pnpm typecheck` 和 `build` 不覆盖全部子包，需要运行递归或指定子包检查。
- better-sqlite3 依赖 Node ABI；切换 Node 主版本后必须重新安装依赖。
- Windows 启动脚本的构建子进程可能产生 Node 的 DEP0190 告警。
- 服务端不托管静态前端资源，默认启动方式同时运行 API 和 Vite 开发服务。
- 部分记忆、备份与恢复测试受本地 OpenViking 服务状态影响；使用隔离的测试环境。
- Windows 上 SQLite WAL 测试并发运行可能产生关闭超时，可用单 worker 复核。
- Mock、本地 stub 和合成数据的测试结果不代表外部生产服务可用性。

所有限制均应结合当前源码和实际检查结果评估。
