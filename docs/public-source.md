# 公开源码边界

此源码快照只包含可公开的程序、合成测试夹具、依赖锁文件和通用文档。
不包含原 Git 元数据或提交历史，也不预置本机项目登记。

本地数据库、日志、凭据、浏览器资料、备份、会话、截图、业务材料和历史验收证据均不分发。
日后运行程序或验证脚本产生的数据应留在 `var/`，个人配置使用被忽略的 `*.local.json`。

`scripts/projects.registry.example.json` 和项目模板中的名称、路径为虚构示例。
安全测试保留合成的密钥、电话、身份证和恶意输入样式，用于验证拒绝及脱敏能力。
这些夹具不应用于连接真实服务。

公开前请重新检查新增文件，并确认许可证和依赖授权信息符合自己的发布要求。
